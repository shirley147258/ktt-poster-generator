# 快团团素材生成器

在浏览器里填商品信息，右侧实时生成 720 × 1280 的团购海报，一键导出 PNG。

所有内容只在**你自己的浏览器**里处理：图片不上传任何服务器，页面不需要联网，也没有账号和后台。

## 怎么用

1. **打开**：双击 `index.html`（Chrome / Edge 都行）。GitHub Pages 上线后也可以直接打开网页用。
2. **选版式**：三种版式的图文位置完全不同，不只是换个颜色——
   **居中促销**（红）：标题、副标题、主图、卖点全部绕中轴对称；
   **左图清单**（绿）：主图靠左，卖点排在图片右侧；
   **大图爆款**（橙）：主图接近通栏铺满，卖点改成横向标签条。
   每个按钮自带一张迷你版面缩略图；当前选中的版式有 ✓ 徽标和主色边框。切换只是重新排版，已填的文字、价格、卖点、两张图都不会丢。
3. **填写**：左边从上到下填——版式、基础信息、图片素材、核心卖点（最多 6 条）、价格和转化文案。**打字即变，不用点生成**。
4. **传图**：商品主图和二维码是**两个独立入口**，各自从本机选文件，换其中一个不会影响另一个。比例选「自动识别 / 3:4 / 1:1 / 保留原图」，适配选「完整展示 / 铺满裁切」——这两项只作用于**商品主图**。整张海报永远是 720 × 1280，传图不会改变海报尺寸。
5. **导出 PNG**：点右下角「导出 PNG」，下载的文件名是 `日期-商品标题.png`，图像真实尺寸 720 × 1280，和预览一模一样。
   导出的是**海报本身**，不含左侧表单、按钮和页面背景；工具会等图片加载完再导，不会出现空白主图。
   万一失败，页面下方会红字说明原因和怎么办，不会假装成功。
6. **「恢复示例」**：用示例内容**替换**当前填写的全部文字、价格、卖点和两张图片（会弹出页面内确认框，写明替换什么、保留什么；点「替换」执行，点「取消」或按 Esc 则内容不变并给出提示）。
   它是**替换**，不是保存也不是撤销；**当前选中的版式会保留**，图片比例回到「自动识别」、适配回到「完整展示」。
   弹窗里点取消的话，什么都不会变。

## 导出的文件在哪 / 怎么确认尺寸

- **在哪**：浏览器的默认下载文件夹。Chrome / Edge 按 `Ctrl + J` 打开下载列表，最近一个 `日期-商品标题.png` 就是它；
  列表里还能直接点「在文件夹中显示」跳转到文件所在目录。
- **怎么确认是 720 × 1280**：
  - Windows：右键文件 → 属性 → 详细信息，看「尺寸」或「水平/垂直分辨率」上方的像素尺寸 `720 × 1280`；
  - 或者把图片拖进浏览器标签页，等它铺满后看图片本身——更直接的办法是在资源管理器里把视图切成「大图标」，缩略图上的尺寸也会显示。
- 注意区分**图片像素**和**屏幕显示大小**：预览区是按比例缩小显示的，导出才是原始 720 × 1280。

## 填写小提示

- 留空的字段在海报上显示灰色占位提示，不会当成 0 或空白误导买家。
- 价格只认数字：负数、乱字符、超过两位小数会在输入框下面红字说明；原价高于团购价时自动算「立省 ¥N」（整数），否则显示中性的「立即跟团」。
- 卖点留空的条目不占号，海报里的序号自动连续；卖点多的版式会自动压缩主图和卖点区的排法，保证价格、二维码和发货信息永远完整落在 720 × 1280 画布内。
- 长文案会自动换行，到行数上限后截断加省略号，不会盖住海报其他区域。
- 图片支持 PNG / JPG / WEBP，只在本机浏览器里读取：不上传服务器、不写进网页源码、刷新即清空。
  选了不支持的文件（如 iPhone 的 HEIC、SVG、0 字节空文件、已损坏的图）会红字说明原因并保留上一张，不会留下「已经选上了」的假象。
- 想回到占位状态就点每个上传框下方的「移除」按钮；换图就是再选一次文件，新图直接覆盖旧的。
- **二维码不会被工具生成，也不会被裁切**：这只是把你自己的码原样排上去（永久**完整展示**：保持比例、四周留白边），并且不受商品图的比例和适配影响。
  没传码时画面上是虚线占位框 + 灰字，那是排版示意，**不是可以扫的购买入口**。
  换上你真实的收款/跟团码后，建议导出 PNG 用手机扫一次确认能识别，再拿去发群。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 唯一的程序文件，HTML/CSS/JS 全在里面，可单文件拷走直接用 |
| `README.md` | 本说明 |
| `.gitignore` | 把 `work/`（临时测试素材）挡在版本库外 |

**不需要独立样式、脚本或图片文件**：图片全部由使用者在网页里临时选择，不打进源码；页面不依赖任何外部 CDN，断网也能用。

## 发布

通过 GitHub Pages 发布：仓库 Settings → Pages → 从 `main` 分支根目录发布。

网站只包含上面 **3 个文件**，没有任何外部依赖；`work/` 里的测试素材不会出现在网页上。
